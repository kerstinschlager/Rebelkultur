# Rebelkultur Shops

Basis einer eigenständigen Shop- und Händlerplattform für Rebelkultur.

## Aktueller Stand

- Responsive Shop-Oberfläche
- Produktsuche und Kategorien
- Warenkorb
- Händler-Dashboard
- Produkte anlegen, bearbeiten und löschen
- Preis, Bestand, Kategorie, Beschreibung und Bild-URL
- Beispiel-Bestellübersicht
- Lokale Demo-Daten per `localStorage`

## Nächster technischer Schritt

Die Demo-Daten werden anschließend durch eine echte Backend-Datenbank, Authentifizierung und sichere Händler-/Admin-Rollen ersetzt. Zahlungsabwicklung und Checkout werden erst danach angebunden.

## Dateien

- `index.html` – Plattformoberfläche
- `styles.css` – responsives Design
- `app.js` – Shop- und Händlerfunktionen
