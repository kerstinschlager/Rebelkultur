# Datenbank

`schema.sql` enthält das erste relationale Datenmodell für Rebelkultur Shops und ist für PostgreSQL/Supabase ausgelegt.

## Reihenfolge

1. Supabase-Projekt anlegen
2. `schema.sql` im Supabase SQL Editor ausführen
3. Authentifizierung konfigurieren
4. Frontend mit Supabase verbinden
5. Row Level Security (RLS) aktivieren und Policies ergänzen
6. Händler-Login und Händler-Dashboard auf die Datenbank umstellen

Es werden keine Zugangsdaten oder Secrets im Repository gespeichert.
